How this system works

Image → 224 × 224 RGB → ImageNet normalization → five trained CNNs → majority vote. The heatmap comes from the final ResNet18 checkpoint and explains its response to the displayed class.

Verified five-epoch baseline

Accuracy 92.15% · pneumonia recall 94.62% · specificity 88.03% · AUC 0.9623. Evaluated on 624 benchmark images. 28 false positives and 21 false negatives.

Lung-focused experiment

The comparison uses a fixed anatomical segmenter at 256-pixel input (a declared CPU runtime adjustment from its standard 512), a bounding rectangle around both lungs with a 10% margin, and matched full-image and crop classifiers. Checkpoints and any ensemble weights use validation data. Cropping can remove useful information and must be evaluated.
