Model  The library is composed of core and baseline classifiers. Core classifiers are trained specifically for this library and baseline classifiers come from other papers that have been adapted to provide the same interface and work with the same input pixel scaling as our core models. All models will automatically resize input images (higher or lower using bilinear interpolation) to match the specified size they were trained on. This allows them to be easily swapped out for experiments. Pre-trained models are hosted on GitHub and automatically downloaded to the user’s local ~/.torchxrayvision directory. Core pre-trained classifiers are provided as PyTorch Modules which are fully differentiable in order to work seamlessly with other PyTorch code. forward ( x : Tensor ) &#x2192; Tensor  The model will output a tensor with the shape [batch, pathologies] which is aligned to the order of the list model.pathologies . preds = model ( img ) print ( dict ( zip ( model . targets , preds . tolist ()[ 0 ]))) # {&#39;Atelectasis&#39;: 0.5583771, # &#39;Consolidation&#39;: 0.5279943, # &#39;Infiltration&#39;: 0.60061914, # ... targets : List [ str ]  Each classifier provides a field model.targets which aligns to the list of predictions that the model makes. DenseNet ( weights_zip = '' , num_models = 30 )  CheXpert ensemble DenseNet classifier An ensemble of up to 30 DenseNet models trained on the Stanford CheXpert dataset, predicting 5 pathologies. Setting num_models to a value less than 30 loads a subset of the ensemble, which reduces memory use and inference time at the cost of accuracy. Targets (5): Atelectasis, Cardiomegaly, Consolidation, Edema, Effusion. Modified for TorchXRayVision to maintain the PyTorch gradient tape and to expose a features() method compatible with the rest of the library. Note This class requires a local copy of the pre-trained weights ZIP file, which must be passed as weights_zip . The weights are not downloaded automatically. VQGAN ( weights = 'cxr2-vqgan-768-sd' , ckpt_path = None , yaml_path = None , cache_dir = None )  VQGAN image autoencoder for chest X-rays A VQ-GAN ( Esser et al., 2021 ) that encodes a chest X-ray into a grid of discrete latent codes and decodes it back. It was built for generating counterfactual explanations with Latent Shift ( Cohen et al., 2021 ): the gradient of a classifier’s output is followed in the latent space, and decoding gives an image the classifier scores as less positive. It was used for the 6th place MIDRC XAI Challenge winner. The native resolution of the model is 768x768. Inputs are expected in the TorchXRayVision pixel range of [-1024, 1024] and are resized by bilinear interpolation automatically. The single channel is repeated to three for the VQ-GAN, and decode returns one channel clipped to [-1024, 1024] at 768x768, regardless of the input size. Available pre-trained weights, both at 768x768 resolution: &quot;cxr2-vqgan-768-sd&quot; — 306 MB checkpoint, 64-dimensional codes on a 24x24 grid (256-entry codebook). &quot;cxr2-vqgan-768-msdd&quot; — 1.23 GB checkpoint, 128-dimensional codes on a 12x12 grid (512-entry codebook). vq = xrv . baseline_models . ieee8023 . VQGAN ( weights = &quot;cxr2-vqgan-768-sd&quot; ) image = torch . ones ( 1 , 1 , 768 , 768 ) z = vq . encode ( image ) # image in [-1024, 1024], shape (B, 1, H, W) image2 = vq . decode ( z ) Parameters : weights – Name of pre-trained weights to download and load. Alternatively pass ckpt_path and yaml_path to use local files. ckpt_path – Path to a local checkpoint (used instead of weights ). yaml_path – Path to the local model config yaml (used instead of weights ). cache_dir – Directory used to store downloaded weights (default: ~/.torchxrayvision/models_data/ ).
